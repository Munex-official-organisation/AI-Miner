# AI-Miner
A AI Based Miner Made Specifically For MCX

It uses Ternsorflow, numpy and more to make a Random Maze and has seen half a million examples
# Explanation of Files
mine.py - Miner for AI-Miner, model.keras dependency
model.keras - 500k maze examples trained model
trainmcxai.py - Training Script
dependency.txt - List of deps for each script
